# AI Agent 学习笔记

《AI Agent：从原理到工程实战》读书笔记与实验记录。
书籍仓库：https://github.com/bojieli/ai-agent-book

## 每章学习方式

每章按以下四步推进，完成一步勾一步：

1. **读正文**：读原书 `book/chapterN.md`；读前先在 questions.md 写下想搞懂的问题，带着问题读
2. **做实验**：按编号顺序做本章全部实验，每做完一个立即写实验记录（复制 `experiments/_template.md` 到 `experiments/` 下本章目录，文件名 `编号-名称.md`，如 `5-3-code-for-math.md`）
3. **写章节笔记**：本章实验做完后，复制 `notes/_template.md` 完成章节笔记——检验理解的核心一步
4. **收尾**：回本页勾选进度；扫一遍 questions.md，勾掉被本章解开的问题

## 目录结构

- `notes/` —— 章节笔记（每章一篇，核心；概念详细内容记在首次主讲的章节里，跨章引用用链接）
- `experiments/` —— 实验记录（每章一个子目录，每个实验一个 md 文件，共 109 个实验）
- `questions.md` —— 未解答问题清单

## 环境准备

在原书仓库目录下执行：

```bash
uv sync --locked --extra ch1   # 按章安装依赖，ch1 换成对应章节编号
cp .env.example .env           # 填入各模型供应商的 API Key
--provider openai --model glm-5.2-external # 修改provider的时候这样修改
--provider deepseek --model deepseek-v4-flash
```
